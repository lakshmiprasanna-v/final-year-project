TOUCHLESS SYSTEM CONTROL THROUGH DYNAMIC HAND TRACKING AND FINGER DISTANCE ESTIMATION USING COMPUTER VISION

<p>Touchless interaction systems are becoming an important advancement in modern Human-Computer Interaction. This project presents a computer vision-based system that allows users to control digital devices without physical contact. </p>
